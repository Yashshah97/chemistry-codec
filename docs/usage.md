# Usage

```python
import chemistry_codec
```

Each module is self-contained; see docstrings for the API:

- `chemistry_codec.chemistry_binary_codec` — Main entry point and top-level module for the Chemistry Binary Codec
- `chemistry_codec.serialization` — Module responsible for serializing and deserializing data to/from binary format
- `chemistry_codec.deserialization` — Module responsible for parsing serialized data from binary format
- `chemistry_codec.versioning` — Module handling versioning of the codec, including serialization and deserialization of versions
- `chemistry_codec.tests_test_codec` — Unit tests for the Chemistry Binary Codec implementation
- `chemistry_codec.core` — main domain logic and public entry points
